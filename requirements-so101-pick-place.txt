# Extra Python packages of the SO101 pick-and-place release (so101_pick_place/README.md). Not part of the paper's
# environment: requirements.txt and environment*.yml are unchanged, and this study does not use them.
#
# 1. Workstation: training, sim checks, bundle build, fake-robot replay (one GPU; scripts/so101_pick_place/reproduce.sh)
#      install the torch / torchvision build for your GPU first (https://pytorch.org), then
#      pip install -r requirements-so101-pick-place.txt
#    Do not add requirements.txt: it pins torch 2.8.0 / torchvision 0.23.0, which this study never ran on. Tested:
#      torch 2.12.0+cu130, torchvision 0.27.1+cu130, Python 3.12.15 (RTX 5090; local runs, smoke runs, the sealed
#      NRD test), torch 2.10.0+rocm7.1, torchvision 0.25.0+rocm (AMD MI350X / MI300X; every training job).
#    AMD GPUs: do NOT install warp-lang from PyPI (that wheel is CUDA only). The renderer ran on AMD's ROCm port of
#      Warp 1.13.0, built from source (scripts/render/hpcfund/build_warp_rocm.sbatch on the branch
#      so101-pick-place-study), with newton installed with --no-deps.
