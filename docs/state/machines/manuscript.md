## Build

Toolchain is **Tectonic** — one static binary, fetches LaTeX packages on demand,
no TeX Live install and no sudo. Installed on `kyle-sbel` at
`~/.local/bin/tectonic` (v0.17.0, x86_64-musl, on `PATH` via `.profile`).

```bash
cd /path/to/Manuscripts/Journal/2026/neural-dynamics-model
tectonic -X compile main.tex
```

~8 s warm (~49 s on the first run of a new machine, fetching the bundle). It
runs BibTeX and reruns for cross-references automatically. To install on a new
box, grab the `x86_64-unknown-linux-musl` tarball from the tectonic GitHub
releases and drop the binary in `~/.local/bin`.

## Two things the repo does not carry

1. **Figures.** `\graphicspath` points at `ImageArchive/journals/2026/neural-dynamics-model/`
   (gitignored) and a sibling `local-image-archive/`. The figure PDFs are
   generated by `scripts/figures/` in this repo but under different names
   (`hmmwv_rl_reward.pdf` in the TeX vs `hmmwv_rl_reward_L8.pdf` in
   `artifacts/analysis/manuscript_figs/`) — the copy/rename step is not checked
   in anywhere.
2. **Bibliography.** `main.tex:187` pulls 17 shared `.bib` files from a
   `BibFiles/` directory, also gitignored and not present. Without it every
   citation renders `[?]` (38 distinct keys, 51 occurrences).
